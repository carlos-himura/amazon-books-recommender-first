# amazon-books-recommender-first

# 📚 Amazon Books Recommender

A hybrid book recommendation engine built on the **Amazon Books Reviews** dataset. It combines **semantic content understanding** (NLP embeddings) with **collaborative filtering** (what similar readers liked) to suggest books a reader is likely to enjoy, including lesser-known titles that go beyond simple "Top Rated" lists.

> This repository is the preliminary work for my master's research in Data Science (Universidad Pontificia Bolivariana). The research builds on it to add offline evaluation, review-text NLP, cold-start analysis, LLM-generated explanations and deployment.

---

## 🎯 Three recommendation strategies

| Goal | Strategy | Type | How it works |
|---|---|---|---|
| **1** | Item-to-item semantic recommendations | Content-based filtering (NLP) | Encodes each book (title + authors + categories + description) into a 384-dimensional vector with `all-MiniLM-L6-v2` (Sentence-BERT) and finds similar books by cosine similarity. |
| **2** | "Readers like you" recommendations | Collaborative filtering (memory-based) | User-based KNN with cosine similarity on mean-centered ratings, plus a 3-level fallback: personalized → genre-based → popular. |
| **3** | Personalized hybrid recommendations | Hybrid (weighted) | Builds a "taste profile" by averaging the embeddings of the user's favorite books (≥ 4 stars), gets candidates from similar users, and ranks them with `Final score = 0.7 × CF + 0.3 × Semantic`, removing duplicate editions. |

**Example output (Goal 3):**

```
TOP 5 HYBRID RECOMMENDATIONS (Behavior + Meaning)
#  | BOOK TITLE                              | SCORE
1  | Jonathan Strange & Mr. Norrell          | 0.7478
2  | Five People You Meet in Heaven          | 0.7142
3  | Night Play (Dark-Hunter, Book 6)        | 0.6774
```

## 📊 Data

**Source:** [Amazon Books Reviews](https://www.kaggle.com/datasets/mohamedbakhet/amazon-books-reviews) by Mohamed Bekheet on Kaggle (2022, CC0: Public Domain). According to its description, it is part of the Amazon Review Dataset (May 1996 – July 2014).

| File | Content |
|---|---|
| `Books_rating.csv` | ~3 million reviews (user, book, rating, review text, date) — 2.7 GB |
| `books_data.csv` | Book metadata (title, description, authors, categories) for 212,404 books |

**Key figures from the EDA:**

| Metric | Value |
|---|---|
| Raw ratings | 3,000,000 |
| Raw users / books | 1,008,972 / 212,403 |
| Users with ≥ 5 ratings | 82,806 (≈ 8%) |
| Final clean ratings (users & books with ≥ 5 ratings) | 385,727 |
| Final users / books | 28,750 / 18,335 |
| Matrix density | ≈ 0.07% |
| 5-star ratings | 53% |
| Book embeddings | 209,452 × 384 |

> ⚠️ The data is **not included** in this repository because of its size. Download it from Kaggle (see *Getting started*). All intermediate files (`.parquet`, `.npy`) are generated by running the notebooks in order.

## 🚀 Getting started

**Requirements:** Python 3.11+. The project was developed on an Apple M3 Pro (PyTorch MPS backend); it also runs on CPU, with slower embedding generation.

```bash
# 1. Clone the repository
git clone https://github.com/carlos-himura/amazon-books-recommender-first.git
cd amazon-books-recommender-first

# 2. Create and activate a virtual environment
python3.11 -m venv recsys_env
source recsys_env/bin/activate        # Windows: recsys_env\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Download the dataset from Kaggle and place both CSVs in Data/
mkdir Data
#    -> Data/Books_rating.csv
#    -> Data/books_data.csv

# 5. Run the notebooks in order (01 → 06)
jupyter lab
```

> 💡 Notebook 03 generates embeddings for ~209K books. On an M3 Pro GPU this takes about 27 minutes; on CPU it can take considerably longer.

## ⚠️ Limitations and next steps

This preliminary work focused on building the pipeline. These are its known limitations, which define the next stage of the research:

| Current limitation | Next step |
|---|---|
| No offline evaluation (no train/test split or metrics) | Evaluate with RMSE/MAE, Precision@K and NDCG@K |
| Review text is not used (embeddings come from book metadata) | Add NLP on review text (embeddings and sentiment) |
| Cold-start users (< 5 ratings) are excluded or handled only by popularity fallback | Evaluate cold-start users and books separately |
| Fixed hybrid weights (70/30) | Compare and tune the combination |
| No explanations for recommendations | Generate natural-language explanations with an LLM |
| Runs only in notebooks | Deploy a web prototype |
